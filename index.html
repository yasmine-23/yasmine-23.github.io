Career Roadmap

My five-year goal is to become a Lead Data Engineer who can design reliable data platforms, own their operation, and guide technical decisions across a team.

Build an end-to-end Azure pipeline

Ingest Olist data into Azure Data Lake, transform it with Databricks and PySpark, and model analytical tables for Power BI. Add incremental loads and verify that rerunning a failed batch creates no duplicates.

Deliverable: versioned pipeline, data model, and architecture diagram.

Automate releases and monitor data

Orchestrate dependencies and retries with Airflow. Run schema, freshness, and data quality tests in GitHub Actions. Set alerts for failed runs and late data, then simulate a failure and recover the pipeline.

Deliverable: CI workflow, monitoring dashboard, and recovery runbook.

Optimize performance and cost

Benchmark Spark jobs before and after tuning joins, partitioning, and file sizes. Record runtime and compute cost to justify the trade-offs.

Deliverable: reproducible benchmark and technical decision record.

Own a production data product

Agree on freshness and reliability targets with stakeholders. Document data contracts and ownership, apply role-based access, and lead an incident review with follow-up actions.

Milestone: end-to-end ownership of a production data product.

Lead technical delivery

Break down a cross-team data initiative into milestones. Lead design and code reviews, define shared testing and deployment standards, and mentor engineers through pairing and feedback.

Milestone: deliver a cross-team initiative and track adoption of the standards.
